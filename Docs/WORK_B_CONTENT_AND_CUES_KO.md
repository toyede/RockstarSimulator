# B 작업: 대사·연출·비교 테스트

## 변경 범위

점수·덱·증강·미션 판정은 변경하지 않는다. 공연장/Rank/게이지의 수동 배치를 보존한다. 아래 비교 항목은 사람의 플레이 결과 없이 기본 정책으로 적용하지 않는다.

## 대사표

| 상황 | 기존 | 적용 | 표정/사운드 |
|---|---|---|---|
| 지하 앰프 확인 | 왜 안 나지. 이쪽이 안 꽂혔나? | 기타 앰프에서 소리가 안 나. 입력 케이블이 헐거운가? | nervous(기본 초상화 폴백) |
| 앰프 사고 | 펑! 스피커에서 큰 소리… | 볼륨을 켠 채 입력 케이블을 뽑는다. 펑! | cable_pop, guitar_stroke 0.83초 |
| 사고 수습 | 일단 손 떼. | 앰프 볼륨부터 내려. 케이블은 내가 꽂을게. | 기존 초상화 |
| 동료 합류 | 일단 첫 곡 해봐. | 첫 곡 인트로 여덟 마디만 맞춰보자. 베이스는 내가 넣을게. | 기존 초상화 |
| 과거 밴드 | 나중에 하자더라. | Verse 2 뒤 베이스 솔로를 빼자더라. 후렴을 한 번 더 넣으래. | 기존 초상화 |
| 라이벌 조언 | 앞에 베이스 나오는 부분은 줄이는 게… | 후렴 앞 베이스 솔로 여덟 마디, 네 마디로 줄여보세요. | LUX//FAUNA 기존 프레임 |
| 너구리의 선택 | 저희는 그 부분도 좋아해서요. | 그 베이스 솔로 듣고 만든 후렴이라서요. 같이 연주하려고요. | 기존 초상화 |

현재 자산은 너구리 기본/기쁨/분노/슬픔, 고슴도치 기본/분노, 라이벌 3프레임이다. nervous 전용 표정·스컹크 스탠딩·앰프 사고 삽화는 신규 아트 요청으로 남긴다. 없는 그림이나 곡명을 임의로 넣지 않는다. 기존 짧고 구체적인 일상 대사·엔딩의 감정 흐름은 보존한다.

`breakdown`은 204초 음악이므로 사고 SFX로 사용하지 않는다. 전용 케이블 팝 SFX를 받으면 해당 줄의 `sfxId`만 교체한다.

## 연출표

| 상황 | 대상/연출 | 반복·복구 |
|---|---|---|
| 입장 | 자리별 0~0.12초 차이, 옆/뒤에서 접근, smoothstep 크기 | 풀 재사용 초기화 |
| 일반 퇴장 | 자리에서 통로로 이동, 크기는 75%까지·알파 감소 | 퇴장 중 재배치 추적 중단 |
| 보스 팬 이동 | 우리 객석은 라이벌 방향(위), 라이벌 팬은 우리 방향(아래) | 기존 인원 이벤트만 사용 |
| 모쉬핏 긍정 | 양옆으로 0.45유닛 벌어졌다가 복귀·작은 점프 | 0.9초, 연속 카드면 최신 큐, 부정 반응은 제외 |
| 마이크/호응 유도 긍정 | 박자에 맞춘 짧은 상하 움직임 | idle/입장/자리 오프셋과 합성 |
| Chill 긍정 | 작은 0.06유닛 호응 | 점수/호응 상태는 변경 안 함 |
| 펑 | 배경만 6px 흔들림 + 최대 18% 플래시 | 0.24초, 스킵/새 줄/비활성 즉시 복구 |
| 신문 | 공연장별 등급 헤드라인 + 실제 보고서 숫자 | 성공/실패 판정 우선, 기존 도장 타이밍 |
| 카드 보충 | 새 종류/추가 장수만 6픽셀 반짝임 | 레이아웃 다음 프레임, Draw/Reroll 기존 VFX 우선 |
| 맵 이동 | 가속·감속, 최대 3px 작은 흔들림·먼지 | 기존 이동 콜백/도착 연출 유지 |
| 시계 | 15초 노랑 작은 펄스, 5초 빨강 강화 | 연장 VFX 우선, 시간 증가/종료/비활성 복구 |

## 큐시트 초안

`Docs/ArtDrafts/CueSheet_20261008_v1/cuesheet_blank.png`: imagegen 내장 도구로 생성한 글자 없는 투명 도트 지면. 기존 튜토리얼 배치에는 아직 자동 적용하지 않는다. 윤빈의 큐시트 최종 디자인과 읽기 영역을 확인한 후 배경 이미지만 교체할 수 있다.

생성 프롬프트: “pixel-art concert stage-manager cue sheet, one flat wide paper panel, transparent exterior, off-white/grey paper, dark ink border/header, tiny binder clip, spacious empty body, no text/characters/scenery, restrained pixel texture.”

## 튜토리얼 비교 방법

Main의 TutorialFlow > `Compact Experience`를 Play Mode에서 켜고 비교한다. 기본값은 꺼짐. 교차 반응 뒤 설명과 게임오버 설명 두 화면을 상태 읽기 체험에 합쳐 클릭 두 번을 줄인다. 3성향 체험, 2초 Hover, 새 관객 관찰, 조명 설명, Fever 체험, 10초/1,000점 실전, Stage 2 Special 교육은 유지한다.

“총 반응”은 `RawAudienceScore`로, “최종 획득 점수”는 `GainedScore`로 따로 표시한다. 둘을 동일한 값이라고 가르치지 않는다.
