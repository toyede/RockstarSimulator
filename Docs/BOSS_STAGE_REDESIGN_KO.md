# 보스전 재설계 기획서 — 「관객 쟁탈전」 (2026-09-16, v2)

담당: 민영 · 검토: 우용(밸런싱) · 윤빈(연출/아트)
대상: Stage 5 「World Stadium Rival Battle」, 룰 `boss_battle`

v2 변경: 2화면(라이벌 무대 | 플레이어 무대)으로 축소, **버튼**으로 라이벌 무대 엿보기(타이머·드레인은 멈추지 않음), 총 관객 대폭 증가(시작은 적게, 적극적으로 뺏어오기),
관객이 라이벌 쪽으로도 이동, 강화 모드 이름 "Revenge Time!", 드레인은 점수만, Revenge 진입 시 카메라 왕복 없음.

**구현 상태 (9/16)**: 6장 목록 전부 구현·E2E 확인. 남은 것은 패턴 경고 UI 를 튜토리얼 모양으로 바꾸는 것(별도 항목)과 우용의 페이스 측정 후 `drainPerFan` 재조정.

## 0. 한 줄 요약

**보스 체력을 없앤다.** 라이벌 LUX//FAUNA 무대에 서 있는 팬 수만큼 일정 시간마다 우리 점수가 깎이고,
제한 시간이 끝났을 때 점수가 목표 이상이면 승리한다. 기존 5개 패턴은 "팬을 뺏어오고 점수를 크게 버는 기회"로 살린다.
라이벌 팬의 과반수를 뺏어오면 **Revenge Time!** — 라이벌이 강화 패턴으로 반격한다.

## 1. 왜 바꾸나

| 지금 (체력제) | 문제 | 바꾼 뒤 |
|---|---|---|
| 체력 = 목표 × 3, 패턴 성공이 체력의 1/8 | 다른 스테이지와 클리어 규칙이 달라 랭크 의미가 없고, 체력 바가 점수와 중복 | 클리어 = 시간 종료 시 점수 ≥ 목표. 랭크 HUD와 랭크 판정 그대로 |
| 패턴 실패 = 체력 회복 | 실패의 체감이 약함 | 실패 = 우리 팬이 라이벌 무대로 건너감 → 매 틱 점수 감소가 커짐 |
| PEAK TIME = 체력 50% 이하 | 플레이어가 잘할수록 강화되는 근거가 약함 | Revenge Time! = 라이벌 팬 과반수를 뺏은 뒤의 반격 |
| 격파 즉시 종료 | 2분 공연의 리듬이 깨짐 | 끝까지 공연. 라이벌 팬 0명이면 감소가 멈추고 남은 패턴은 전부 보너스 기회 |
| 3화면(라이벌·스탠딩석·우리) | 가운데 화면이 하는 일이 없음 | 2화면. 라이벌 무대가 바로 옆이라 팬이 건너가는 게 보인다 |

## 2. 핵심 루프

```
        라이벌 무대 (x = −19.2)        │        플레이어 무대 (x = 0, 조작)
        라이벌 팬 R명이 서 있다         │        우리 관객 M명
                                       │
  매 drainInterval 초마다  점수 −(R × drainPerFan)      카드 판정·피버는 평소와 같이 점수 +
  패턴 성공 → 라이벌 팬 2명(강화 3명)이 오른쪽으로 건너옴 + 보너스 점수
  패턴 실패 → 우리 팬 1명이 왼쪽으로 건너감
  R ≤ 6 (시작 14의 과반수 상실) → Revenge Time!: 강화 패턴, 간격 단축, DROP 등장
  [120초] 점수 ≥ 목표 → 승리 (랭크 = 점수/목표) / 미만 → 패배
```

플레이어의 목표는 두 가지가 동시에 굴러간다. **점수를 벌기**(평소 플레이)와 **감소량을 줄이기**(패턴으로 팬 뺏기).
시작 관객이 적고 라이벌 쪽이 많으므로 "빼앗아 채운다"는 느낌이 기본이다. 실패가 쌓이면 감소가 눈덩이처럼 커진다.

## 3. 규칙 상세

### 3.1 팬 분포 — 총 20명, 우리 6 / 라이벌 14 로 시작

| 항목 | 값 | 비고 |
|---|---|---|
| 우리 관객 시작 / 정원 | 6 / 20 | 프리셋 `audience_stadium_final` 수정. 다른 스테이지(8~12)보다 적게 시작 |
| 라이벌 팬 시작 | 14 | `rivalFanPool` |
| 총 팬 | 20 | 우리 + 라이벌 = 항상 20. 자연 이탈은 "라이벌 쪽으로 건너감"으로 처리 (총원 불변) |
| 우리 관객 하한 | 3 | `minimumSurvivors` |

관객 배치(AudienceRosterPresenter)가 20명을 놓을 수 있는지 구현 전에 확인한다. 자리가 모자라면 총 16(우리 5 / 라이벌 11)으로 축소.

### 3.2 점수 감소 (드레인)

| 항목 | 값 |
|---|---|
| 주기 `drainInterval` | 4초 |
| 1명당 감소 `drainPerFan` | 12점 |
| 첫 감소 시작 `drainStartDelay` | 8초 (첫 패턴 예고보다 먼저 "왜 깎이는지" 보여준다) |
| 감소 하한 | 점수 0 아래로 내려가지 않음 |
| 감소 중단 | 라이벌 팬 0명 |

라이벌 팬 14명 유지 시 4초마다 −168(초당 42점), 7명이면 초당 21점, 0명이면 0.
목표 페이스가 초당 100점(12,000 / 120초)이므로 아무것도 안 뺏으면 총 약 5,000점을 더 벌어야 한다(체감 목표 17,000).
**"패턴을 하나도 못 깨면 클리어가 어렵고, 절반만 깨도 편해진다"** 가 의도.

### 3.3 승패와 랭크

- 승리: 120초 종료 시 점수 ≥ 12,000. `PerformanceTimer.Failed` 판정을 그대로 쓴다 (보스 룰이 판정을 덮어쓰지 않음).
- 랭크: 다른 스테이지와 같은 `ScoreRankUI` 구간 (D 1.0 / C 1.6 / B 2.4 / A 3.6 / S 5.0). 랭크·점수·시간 HUD를 보스전에서도 보여준다.
- 조기 종료 없음. 라이벌 팬 0명이 되어도 공연은 끝까지 간다(남은 패턴은 전부 보너스 기회).

### 3.4 패턴 (기존 5개 유지, 역할만 바뀜)

| 패턴 | 기본 | 강화(Revenge) | 성공 | 실패 |
|---|---|---|---|---|
| B2B 맞받아치기 | 지목 카드 1장 | 2장 | 팬 +2, 보너스 6% | 팬 −1 |
| GUEST LIST 팬 영입 | 손패 Special 로 요청 성공 | 창 6초 | 팬 +2(강화 +3), 보너스 6% | 팬 −1 |
| BEATMATCH 흐름 유지 | 콤보 유지 + 카드 2장 | 3장 | 팬 +2, 보너스 6% | 팬 −1 |
| KILL SWITCH 성향 봉인 | 봉인 1성향, 양수 반응 2번 | 2성향, 3번 | 팬 +2, 보너스 6% | 팬 −1 |
| DROP | (Revenge 전용) 피버 진입 | — | 팬 +3, 보너스 10% | 팬 −1 |

- 보너스 = 목표 점수 × 비율 (6% = 720점, 10% = 1,200점). 감소분을 되돌려 주는 크기라 "기회"로 느껴지게.
- 스케줄: 첫 예고 10초, 종료 후 간격 10초, 창 8초, 예고 연출(카메라 왕복 3.8초, 타이머 정지)은 유지 → 공연당 약 5회. Revenge 진입 후 간격 7초.
- 팬 이동은 즉시 반영되어 다음 드레인 틱부터 감소량이 바뀐다. 이동하는 팬은 두 무대 사이를 실제로 걸어간다(2화면이라 보인다).

### 3.5 Revenge Time! 진입·해제

- 진입: 라이벌 팬 ≤ 6 (시작 14명 중 8명 이상이 우리 쪽으로). 진입 시 "REVENGE TIME!" 자막 + 조명 색 진홍 + 라이벌 무대 LED 진홍 + 즉시 DROP 1회.
- 해제: 실패로 라이벌 팬이 다시 9명 이상이 되면 기본 모드로 (오락가락 방지 히스테리시스).
- 라이벌 팬 0명: 드레인 0, 패턴은 계속 나오되 성공해도 팬 이동 없이 보너스만.

### 3.6 실패의 무게

패턴 실패로 우리 팬이 넘어가면 그 팬이 왼쪽 라이벌 무대로 걸어가는 연출을 보여주고, 다음 틱부터 감소가 12점 늘어난다.
우리 관객이 3명 아래로는 내려가지 않는다.

## 4. 화면 · UI · 연출

### 4.1 2화면 배치와 라이벌 무대 들여다보기

```
[ 라이벌 무대  x = −19.2 ]  [ 플레이어 무대  x = 0 ]
  듀오·LED·라이벌 팬 R명       우리 관객 M명 (조작)
```

- 가운데 스탠딩석 구역은 삭제. `BossArenaLayout` 은 구역 2개(Rival, Ours)만 만든다.
- 라이벌 팬은 라이벌 무대 앞에 실제 관객처럼 서 있다(첫 구현은 실루엣 Square, 아트가 오면 관객 스프라이트 흑색 실루엣).
- **엿보기 버튼**: 화면 왼쪽 가운데 "< 라이벌 무대" 버튼을 누르면 카메라가 라이벌 무대로 팬(1.0초). 현재 예고 연출과 같이 손패가 내려가고 카드 입력이 잠긴다.
  버튼은 오른쪽 가장자리로 옮겨 "우리 무대 >" 가 되고, 누르면 돌아온다(1.0초). 돌아오면 손패가 올라오고 입력이 풀린다.
- 들여다보는 동안 **타이머·드레인·호응 감소는 멈추지 않는다** (예고 연출과 다름). 보는 데 시간을 쓰는 것이 대가. 패턴 예고·창 중에는 버튼이 비활성이고, 엿보기 중에 예고가 오면 그 자리에서 예고 연출로 이어진다.
- 패턴 예고 왕복은 지금처럼 자동(타이머 정지 유지).

## 7. 확정 사항 (9/16)

1. 관객 배치는 5열 × 행 증가 방식이라 20명을 수용한다 (E2E 로 우리 15명까지 확인). 총 20 확정.
2. 드레인은 점수만 깎는다.
3. 엿보기 중 타이머·드레인·호응 감소는 멈추지 않는다. 엿보기는 버튼으로 한다.
4. Revenge 진입 시 카메라 왕복은 넣지 않는다 (자막 + 색 변화만).
5. 패배 시 신문 기사는 "라이벌의 앙코르"로 마무리, 재도전 버튼은 없음.
