# 인게임 효과음 연결 — 이어하기 기록

범위: 카드 슬랩베이스, 미션 등장·성공, 투어 허브 포스터 시작, 방송국 정전, 보스 드랍.
튜토리얼 전용 스테이지 분리는 다음 회의까지 보류한다. 커밋, 푸시, 빌드, 배포, 점수 업로드는 여기서 하지 않는다.

## 시작 상태

- 브랜치 `sub-developing`, 시작 커밋 `8ac9510` (`[feat] 아트 에셋 + 오디오 에셋 추가`). 시작 Git 상태는 깨끗했다.
- 열린 Unity 6000.3.20f1 Editor에 연결했다. 원본 오디오 11개가 모두 AudioClip으로 임포트되어 있었다.
- `slapbass_1.flac` 4.566초, `slapbass_2.wav` 1.878초. `amp_connection.wav` 유효 신호는 약 0.223초부터 시작한다.

## 구현 및 재개

- 코드: `DialogueTypes`, `DialoguePanel`, `TourPrototypeUI`에서 포스터 확인 시점에만 전용 효과음 요청.
- 코드: `StageEventNoticeUI`, `MissionCueSheetView`, `BossBattleUI`에서 일반 미션 등장·성공에 사운드 요청. 보스의 상시 관객 미션은 포함하고, 보스 패턴 본체의 예고·결과는 기존 연출 유지.
- 코드: `BlackoutPresentation`에서 정전 진입에 전기음. 미션 등장 마이크 음은 정전에서만 0.75초 늦춰 전기음과 분리.
- 코드: `BossStagePresentation`에서 원래 드랍 타이밍에 스페셜 클립을 0.5배로 한 번, 128 BPM으로 1–2–1–2 킥 재생. 공연 종료·재시작 시 남은 타격 예약을 정리한다.
- 에셋: Unity Editor에서 `slapbass_1_Play_2p1s.wav`(끝 12ms 페이드)와 `amp_connection_Click.wav`(앞 무음 205ms 제거)만 추가했다. 원본은 유지했다.
- 사운드 라이브러리: 행사·UI 신규 ID 7개를 저장했다. Editor에서 슬랩베이스 **2.100초 / 1.878초**를 확인했다.
- 카드 범위 보강: 대사도 일반 기타 ID를 참조하므로 기타 풀을 기존 4개로 복구하고, 카드 코드에서만 1/3 확률로 `card_slapbass`(두 클립 랜덤)를 선택하도록 분리했다. 에디터에서 기타 4개, 베이스 2개 확인. 1스테이지는 어쿠스틱 선택 유지.

## 확인 결과

- Unity 컴파일 오류 없이 완료. `git diff --check` 통과.
- Play Mode: 1스테이지 어쿠스틱 및 이후 카드 효과음 분기, 마이크 3종 랜덤 선택, 소나기·정전 성공/실패, 소나기 결과 중복 방지, 정전 전기음과 마이크 음 분리 확인.
- Play Mode: 실제 포스터 버튼을 테스트 클릭해 열릴 때가 아니라 누를 때 앰프음이 UI 버스에서 한 번만 재생되는 것을 확인. 씬 전환 콜백은 테스트용으로 대체했다.
- Play Mode: 보스 예고 1회에 킥 `1–2–1–2`와 50% 스페셜 드랍 1회. 일시정지 없이 이어진 두 타격 간격 각각 0.470초. 일시정지 및 스테이지 이탈 시 남은 킥도 확인했다. 보스 상시 관객 미션은 일반 시작·성공음으로 연결됐다.
- Play Mode를 종료하고 `Title`로 돌아왔다. 테스트로 씬 파일을 저장하지 않았다. 실제 스피커/이어폰에서 BGM·카드음과의 믹스 청취 및 WebGL 빌드는 확인하지 않았다.

사용량 제한에 맞춘 자동 재시작은 설정되지 않았다. 재개 시 이 문서와 실제 Git diff부터 확인한다. 클립이나 ID가 이미 등록돼 있으면 중복 추가하지 않는다. 다음은 실제 믹스 청취와 WebGL에서 소리 재생 확인이다.
