# 작업 A 적용 및 검증 기록

> 후속 수정: 사용자 요청에 따라 투어 디버그 입력·안내는 다시 기본 활성화했다. 아래의 기본 차단 검증은 최초 작업 A 적용 시점의 기록이다. 에디터 메뉴로 필요할 때만 끌 수 있고, 정식 릴리즈 빌드의 기존 조건부 제외는 유지한다.

## 적용 범위

Stage 1 StageSet의 수동 배치를 보존하고 표시 문제를 수정했다. 작업 B, 카드 판정·점수 공식·증강 효과·보스 미션 조건은 변경하지 않았다.

| 항목 | 적용 내용 |
|---|---|
| 투어 디버그 | 평소 투어에서는 강제 종료·이벤트·관객·열기·조명 디버그 입력과 안내를 차단한다. 검증할 때만 Play Mode에서 `Tools/Tour/Enable Debug Controls`로 켠다. 단독 Main의 기존 디버그 기능은 유지한다. |
| 보스 타이머 | 보스 연출의 타이머 숨김 설정을 해제했다. 기존 시계 UI를 그대로 사용한다. |
| 보스 미션 | 왼쪽 위 시계 아래로 배치하고 제목·제한시간·설명 영역을 분리했다. 우상단 랭크 이미지와 게이지 위치는 변경하지 않았다. |
| 일시정지 | 활성 HUD 위에 블러와 메뉴를 정렬하고 전체 팝업 영역에 투명 입력 차단판을 둔다. 옵션은 Pause 위에 표시한다. |
| 결과 중복 | 투어 GameOver에서는 기존 GameOverPopup 자동 표시를 막고 신문 결과창만 사용한다. 단독 Main의 기존 결과 경로는 유지한다. |
| 스테이지 조명 | Stage 2~5의 위치·반경·각도·움직임 프로필을 추가했다. Stage 1은 원래 조명 설정으로 돌아간다. 성향에 따른 조명 색 힌트는 그대로다. |
| 신문 폰트 | 둥근모 폰트로 통일하고 제목·후기 영역 및 자동 크기 범위를 조정했다. 기사 내용 자체는 수정하지 않았다. |

## 씬 설정

Main에 변경 사항을 저장했다. 씬/에셋 변경은 연결된 Unity Editor에서 처리했다.

- `ST01_FG_AmpLeft`: 위치 `(-7.73, -3.05, 0)`, 크기 `(0.48, 0.48, 0.48)` 유지.
- `ST01_FG_GuitarCaseRight`: 위치 `(2.87, -2.29, 0)`, 크기 `(0.41, 0.41, 0.41)` 유지.
- Stage 2~5 조명은 `StageLightController.stageGeometry`에서 개별 조절 가능하다.
- 기존 StageSet과 배경 카탈로그의 연결을 유지했다. Stage 4의 비어 있는 소품 세트에 임의의 새 아트를 넣지 않았다. 보스는 기존 전용 무대 연출을 사용한다.
- `Tools/Playtest/Apply Work A To Main`은 Main의 Edit Mode에서 해당 설정을 다시 적용하는 보조 메뉴다. 사용 시 결과 폰트·미션 배치·Stage 2~5 조명 프로필을 기본값으로 덮어쓰므로 수동 조정 후에는 재실행하지 않는다.

검증은 임시 메모리 투어 상태와 자동 호출을 사용했다. 서버 점수 제출이나 저장 데이터 삭제는 하지 않았다. 테스트용 TutorialFlow.SuppressForTests는 false로 복구했고 Play Mode는 종료했다.

### 아직 수동 확인할 항목

- Title부터 증강·맵·다음 공연·엔딩까지 실제 버튼 조작으로 완주하기.
- 보스의 모든 예고/미션, Fever, 이벤트 중 ESC 반복 입력과 재개 확인.
- Stage 2~5 조명 모양과 새 미션 위치의 최종 미술 조정. 모든 공연장 구도를 스크린샷으로 비교한 것은 아니다.
- A/B/C/D 등급별 기사, 다양한 창 크기, 모바일 및 WebGL 빌드.
- 실제 마우스 클릭이 Pause 아래 카드에 전달되지 않는지 입력 플레이 테스트.

## 변경 보존 주의

작업 시작 전 Main 씬, DungGeunMo SDF 폰트와 아트 메타 파일 8개에 기존 변경이 있었다. 이를 되돌리지 않았다. 동적 TMP 폰트는 검증 중 필요한 글리프/아틀라스를 추가해 파일 변경량이 커질 수 있다. 전체 폰트를 git으로 되돌리면 기존 팀원 변경도 사라질 수 있으므로 주의한다.

`git diff --check`에서 소스의 공백 오류는 없었다. Unity가 직렬화한 동적 폰트 에셋에는 빈 YAML 필드의 trailing whitespace가 보고되었다. 에셋 YAML을 수동으로 수정하지 않았다.
