- 월드 조명은 Effects 레이어 -100, 반응/말풍선/Overlay UI 아래. 기존 랭크·게이지·카드 위치 변경 없음.
- 지하 공연장: 같은 성향 힌트색의 전체 워시, 확정된 성향 변경에만 동기화 펄스. 기본 완화 점멸 유지, 초기 입장에는 펄스 없음.
- 페스티벌: 기존 배치 유지, 12초 간격 2.5초 객석 보조 스윕.
- 방송국: 시작 시 좌→중→우 순차 점등, 대표 카드 사용 후 0.8초 방향성 밴드 역광. 비활성 밴드 포함 4개 원본 렌더러에 연결, 실제 활성 3개 확인.
- 보스: 평소 4 / 드랍 6 / 드랍 예고 피크 8 레이저. 카메라가 라이벌 무대에 체류할 때 전반 정적→후반 펼침. 미션 조건·카메라 시간·음악 변경 없음.
- Fever 별도 광원 강도 0.85배, Rig 에너지 상승 1.55→1.3. 암전이 Fever·워시·레이저·LED·스모그보다 우선.

## 확인 범위의 한계

- 보스 예고는 합성 이벤트로 시작했으며 실제 미션 성공/실패 판정은 변경하거나 재설계하지 않았다.
- Editor 렌더링/상태 검증이지 WebGL 브라우저·모바일·다른 GPU 검증은 아니다.
- 점멸과 밝기에 대한 사람의 취향/광과민성 테스트는 별도 필요. 완화 점멸을 기본 유지한다.
- 검증은 저장된 씬에서 수행하며 시험용 PlayerPrefs/점수 기록은 만들지 않는다.
