# 1. 제출 전략

Raccoon Roll은 2026년 7월 48시간 게임잼에서 시작한 프로젝트다. 이번 제출에서는 게임잼 결과물을 그대로 재제출한 것으로 보이지 않도록 다음 세 단계를 명확히 구분한다.

1. **게임잼 버전의 출발점** — 단일 공연에서 관객을 읽고 카드를 내는 코어 플레이
2. **챌린지 기간에 실제로 추가한 기능** — WebGL, 접근성, 동적 이벤트, 서버 랭킹, 투어·증강 구조
3. **출시 버전으로 확장 중인 내용** — 다섯 공연장, 밴드 합류 스토리, 보스 공연

현재 공개 WebGL 빌드에서 플레이할 수 없는 기능은 `출시 확장 프로토타입` 또는 `통합 중`으로 표시한다.

# 2. 신청서용 200자 게임 소개

> 관객의 복장과 움직임을 읽고 애드리브 카드를 선택해 공연을 완성하는 픽셀아트 전략 카드 게임입니다. 같은 카드도 관객마다 다른 반응을 만들며, 콤보·피버·스페셜 관객·돌발상황을 활용해 최고 랭크에 도전합니다.

# 3. itch.io 설명란 추가 문구

아래 블록을 기존 게임 소개와 조작법 사이 또는 설명 최하단의 개발 노트 영역에 삽입한다.

```markdown
## 기존 프로젝트 활용 및 챌린지 기간 개발 내용

Raccoon Roll은 2026년 7월 48시간 게임잼에서 시작된 프로젝트입니다. OpenAI Game Builders Seoul 챌린지 기간에는 기존 빌드를 그대로 재제출하지 않고, Codex와 함께 실제 브라우저에서 바로 플레이할 수 있는 데모로 고도화하는 동시에 출시 버전의 투어 구조까지 확장했습니다.

### 플레이 가능한 제출 빌드에 새로 구현·고도화한 내용

- 플레이 흐름과 성적에 따라 **관객 이탈 위기** 또는 **힙스터 팬 합류**가 발생하는 적응형 돌발상황 시스템
- 관객 반응, 점수·콤보 변화, 타이머, 스페셜 카드를 즉시 구분하게 하는 픽셀 파티클·카드 트레일·발광 VFX
- 셰이더 기반 카드 디졸브·화면 왜곡·픽셀 조명과 신규 VFX를 결합한 공연 연출 폴리싱
- 관객 Hover 대사, 타이핑 연출, 조명 힌트와 실전 체험을 포함한 튜토리얼 전면 개편
- PC Hover를 유지하면서 모바일 WebGL에서도 관객을 길게 눌러 취향과 대사를 확인할 수 있는 터치 조작
- 원격 점수 저장, 타이틀 화면 온라인 리더보드와 실패·재도전 흐름
- Unity WebGL 빌드, 브라우저 전체화면·종료 동작, 화면 크기와 압축·호환성 문제 개선

### 챌린지 기간에 개발한 출시 확장 구조

- 공연 결과에서 다음 공연으로 이어지는 Tour Run 상태와 5개 StageDefinition 데이터 구조
- `공연 → 결과 → 증강 선택 → 맵 → 다음 공연`으로 확장 가능한 진행 구조
- 세 후보 중 하나를 선택하고 각 후보를 개별 리롤할 수 있는 증강 선택 화면
- 9종 증강, Bronze·Silver·Gold 3단계, 보상 테이블과 런 단위 누적 효과
- 앙코르·무대 장악 등 신규 카드 계열과 증강 연동 효과
- 골목 버스킹, 지하 라이브홀, 록 페스티벌, 아레나, 월드 스타디움의 스테이지 배경·맵 썸네일 제작

Codex는 기존 Unity 프로젝트 조사, 시스템 책임 분리, 기능 구현과 버그 진단, WebGL·모바일 대응, 플레이테스트 피드백 정리와 반복 개선에 활용했습니다. 핵심 게임 규칙, 재미 판단, 밸런스, 아트 방향과 최종 우선순위는 팀이 직접 결정했습니다.

※ 투어·증강·신규 스테이지는 출시 버전용 확장 기능으로 통합 및 폴리싱 중입니다.
```

## 공개 빌드 갱신 후 바꿀 문장

투어와 증강이 실제 제출 WebGL 빌드에서 처음부터 끝까지 플레이 가능해진 경우 마지막 문장을 다음처럼 변경한다.

```text
※ 현재 제출 빌드에서는 단일 공연뿐 아니라 공연 결과 이후 증강을 선택하고 다음 무대로 진행하는 투어 프로토타입까지 직접 확인할 수 있습니다.
```

## 현재 itch.io 페이지에서 함께 고칠 부분

현재 페이지의 `마우스 전용` 표기는 모바일 길게 누르기 기능과 맞지 않는다. 다음처럼 수정한다.

```text
[조작법]
- PC: 마우스로 UI 선택·카드 드래그, 관객 위에 올려 정보 확인
- 모바일: 터치로 UI 선택·카드 드래그, 관객을 길게 눌러 정보 확인
- 일시정지: ESC
```

현재 게임 목표 2번의 `손에 쥐세요].` 오탈자는 `손에 쥐세요.`로 고친다.

# 5. 데모 영상 기본 방향

## 목표

영상을 본 사람이 3분 안에 다음 네 가지를 이해해야 한다.

1. 관객을 읽고 카드를 고르는 게임이다.
2. 같은 카드도 관객에 따라 결과가 달라진다.
3. 콤보·피버·스페셜 관객·돌발상황이 공연의 흐름을 바꾼다.
4. 게임잼 이후 Codex와 함께 WebGL 서비스와 투어·증강 구조까지 확장했다.

## 권장 길이

- 최종 러닝타임: **2분 40초~2분 50초**
- 공식 제한인 3분을 꽉 채우지 않는다.
- 실제 게임 화면 비중: 최소 75%

# 7. 내레이션 원고

> Raccoon Roll은 관객의 맥락을 읽는 전략 카드 공연 게임입니다.  
> 관객의 복장과 움직임은 그들이 원하는 공연의 힌트입니다.  
> 같은 애드리브도 누군가는 열광하고, 누군가는 지루해합니다.  
> 좋은 판단을 이어가면 콤보가 쌓이고 피버 타임이 무대를 폭발시킵니다.

> 공연 결과는 랭크와 온라인 리더보드에 기록됩니다.  
> 게임잼 이후 Codex와 함께 모바일 조작, 동적 이벤트, 서버 랭킹, 9종의 증강과 투어 확장 구조를 새롭게 개발했습니다.  
> 관객을 읽고, 흐름을 쌓아, 무대를 뒤집어 보세요.

# 9. 편집 규칙

## 화면

- 1920×1080, 16:9, 60fps 권장
- 디버그 로그·디버그 버튼·Unity Console이 게임플레이 장면에 노출되지 않게 한다.
- 마우스 커서는 숨기지 말고 클릭 위치가 보이게 한다.
- 카드 선택 장면은 1배속을 유지한다. 대기 시간만 1.5~2배속 또는 점프 컷한다.
- 핵심 UI를 가리지 않도록 자막은 좌측 하단 또는 화면 중앙 하단에 배치한다.
- 자막은 최대 두 줄, 한 줄 22자 안팎으로 제한한다.

## 사운드

- 게임 BGM과 카드·관객 효과음을 그대로 사용해 실제 반응성을 보여준다.
- 내레이션이 있으면 BGM을 약 8~12dB 낮춘다.
- 피버와 스페셜 성공 순간에는 내레이션을 잠시 비워 함성과 효과음이 들리게 한다.
- 사용 음원과 효과음의 라이선스 및 크레딧을 영상 설명란에 표기한다.

## 자막 색상

- 기본 설명: 흰색
- 관찰·정보: 청록
- 성공·콤보: 노랑 또는 금색
- 위험·실패: 빨강
- `챌린지 신규 개발` 표시는 주황색 고정 라벨로 통일
