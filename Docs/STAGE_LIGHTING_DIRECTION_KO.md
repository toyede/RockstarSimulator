# RACCOON ROLL — 스테이지별 조명 세부기획

상태: 제안 / 게임 코드와 씬에는 아직 적용하지 않음.

기준: 현재 스토리 바이블, Stage01~05 설정, 보스 관객 쟁탈전 구조. Stage 4의 데이터 표시명은 Arena Headliner지만, 이 문서의 연출은 현재 스토리의 **생방송 무대**를 기준으로 한다. 스테이지 수·관객 비율·승패 조건·미션은 변경하지 않는다.

## 1. 전체 방향

> 골목을 잠깐 무대로 만들던 밴드가, 남이 만든 무대에 적응하고, 마지막에는 자기 공연으로 관객을 데려온다.

조명의 수보다 **광원이 설치된 장소와 움직이는 방식**이 달라져야 한다.

| 스테이지 | 장소 / 이야기 | 고정 테마 | 조명의 특징 |
|---|---|---|---|
| 1 | 퇴근길 골목, 너구리와 고슴도치의 첫 공연 | Chill 시안 | 가로등·상점 불빛, 작고 거의 정지 |
| 2 | 지하홀, 앰프 사고와 스컹크 합류 | Mosh 빨강 | 낮은 천장의 짧은 직하광, 거친 역광 |
| 3 | 야외 페스티벌, 선배의 과거와 팬들의 목소리 | Singalong 보라 | 넓은 객석 워시, 함께 펼쳐지는 부채꼴 |
| 4 | 첫 생방송, 긴장한 세 사람 | 백색 / 청회색 + 작은 방송 빨강 | 정확하고 반듯한 면광원, 카메라 탤리·LED |
| 5 | 스타디움, LUX//FAUNA와 서로 다른 공연 방식 | 우리: 중성 백색·호박색 / 라이벌: 마젠타·시안 | 아래와 위의 두 무대, EDM 레이저·LED 체이스·스모그 |

### 테마색과 힌트색은 다른 정보

1. **공연장 테마**: 벽·바닥 가장자리·간판·후면 LED. Stage 1~3의 시안/빨강/보라를 유지한다.
2. **관객 성향 힌트**: 관객 가까운 작은 전용 조명. 기존 최다 성향 판정을 유지한다. 고정 테마와 같은 넓은 조명을 공유하지 않는다.
3. **동작/상황 표시**: 관객 요청 강조, 피버, 방송 사고, 보스 패턴. 이벤트가 켜질 때만 해당 영역에 표시한다.
4. **가독성 기본광**: 관객의 복장과 표정, 밴드 윤곽을 읽게 하는 낮은 중성광. 평상시 유지한다.

고정 테마는 해당 성향 관객이 항상 다수라는 뜻도, 같은 색 카드가 무조건 성공한다는 뜻도 아니다. 힌트색 역시 개별 반응의 성공 보장이 아니라 현재 구성에 대한 보조 정보다.

반복적인 전체화면 플래시·관객 전체 틴트는 사용하지 않는다. 효과는 배경과 무대 가장자리에 집중한다. 아래 시간은 첫 제작의 시작값이며 실제 화면에서 조정한다. 음악 박자 동기화가 없는 상태에서 임의 주기를 ‘박자에 맞춘 조명’이라고 설명하지 않는다.

## 2. Stage 1 — 골목 버스킹 / Chill

### 구성

- 따뜻한 가로등 1~2개: 인도에 짧은 빛 웅덩이. 공연장용 교차 스포트라이트는 지양한다.
- Chill 시안: 상점 유리·작은 휴대용 무대등·간판 가장자리에서 약하게 사용한다.
- 너구리와 고슴도치를 한 작은 빛 영역 안에 둔다. 아직 두 사람뿐인 출발이 보이게 한다.
- 맞은편 LUX//FAUNA 광고는 골목 조명보다 정돈되고 선명하다. 단, 플레이 중 광고 깜빡임을 지속해 관객보다 시선을 빼앗지는 않는다.

### 플레이 시나리오

1. 공연 시작: 휴대용 조명이 약 0.4초에 걸쳐 켜진다. 광원 고장·입력 잠금 같은 새 규칙은 없다.
2. 첫 성공: 무대등이 잠깐 밝아지고 돌아온다. 매 카드마다 모든 상점이 반응하지 않는다.
3. 피버: 상점 창문 2~3개가 순서대로 켜지고 시안 빛 웅덩이가 넓어진다. 비로소 골목이 무대처럼 보인다.
4. 피버 종료: 창문 강조가 서서히 줄어든다. 기본 가로등은 꺼지지 않는다.

Stage 1 StageSet의 완료된 소품 위치·크기는 건드리지 않는다. 추가 광원은 실제 가로등·앰프 위치를 기준으로 둔다.

## 3. Stage 2 — 지하 라이브홀 / Mosh

### 이야기의 조명

너구리가 케이블을 뽑아 ‘펑!’ 하는 사고, 스컹크가 장비를 살펴보고 베이스를 얹는 장면을 연결한다. **허름한 장비지만 세 사람의 공연은 단단해지는 공간**이다.

### 광원 배치

- 낮은 천장: 작은 빨간 등 3개. 빛은 짧고 좁게 바닥으로 내려온다. 높은 스타디움 조명처럼 긴 X자로 교차하지 않는다.
- 무대 뒤 벽: 붉은 고정 워시. Mosh 테마의 주된 면적은 여기다.
- 드럼 뒤 / 밴드 발밑: 역광 2개. 평소 약하고, 피버 때 밴드 윤곽을 세운다.
- 객석: 중성 보조광과 작은 성향 힌트등. 빨간 벽 때문에 정장·트레이닝복까지 빨갛게 물들지 않게 한다.
- 기존 빨간 테마 소품은 유지. 하얀 연기나 짙은 안개를 새 필수 요소로 만들지 않는다.

### 장면별 큐

| 시점 | 화면에서 일어나는 일 | 읽히는 의미 |
|---|---|---|
| 대사 ‘펑!’ | 앰프 위치에서 짧은 밝기 펄스, 천장 등 한 개가 1회 흔들리고 안정됨 | 장비 사고. 공연 전체 정전과 구분 |
| 스컹크의 베이스 테스트 | 그가 서 있는 무대 끝에 중성광이 켜짐 | 두 사람뿐이던 빛 영역에 한 명이 들어옴 |
| 공연 시작 | 세 천장 등이 약 0.15초 간격으로 켜짐 | 좁은 무대가 준비됨 |
| 일반 카드 성공 | 천장 등 하나의 강도만 짧게 상승 | 작은 방에서 즉각 돌아오는 호응 |
| 특별 관객 요청 | 요청 관객 위에 작은 밝은 테두리/후광, 요청색은 이 강조 영역에만 사용 | 누가 무엇을 요구하는지 |
| 특별 요청 성공 | 해당 관객 후광이 커졌다 사라짐, 가까운 등 하나가 응답 | 요청을 제대로 들었음 |
| 피버 | 뒤쪽 역광이 강해지고 세 빨간 천장 등이 동시에 밝아짐 | 좁은 공연장이 꽉 차는 열광 |

### 실제 플레이 예

빨간 벽 아래 관객들이 서 있다. 플레이어는 빨강을 정답으로 읽는 것이 아니라 관객 복장과 호응도를 본다. 특별 관객의 요청이 생기면 작은 후광이 그 관객만 강조한다. 맞는 Special이 성공하면 후광이 터지고, 피버 때는 뒤의 역광이 세 밴드를 하나의 실루엣으로 묶는다.

### 피할 것

- Mosh 카드가 나오면 무조건 전 화면 빨간 플래시.
- 아무 성공이나 역광 최대 출력: 피버의 차이가 사라진다.
- 앰프 사고의 깜빡임을 플레이 내내 반복하는 연출.
- 특별 관객 주변의 일반 관객을 어둡게 지워 요청만 읽게 하는 연출.

## 4. Stage 3 — 록 페스티벌 / Singalong

스컹크의 미발매 곡과 떠나지 않은 팬들의 대화가 중심이다. ‘대형 장비’보다 **멀리 있는 사람들까지 같이 노래하는 공간**을 보여준다.

- 하늘·노을은 중성적인 환경광. Singalong 보라는 높은 트러스와 객석 가장자리에서 사용한다.
- 3~5개의 빛을 넓은 부채꼴로 펼친다. 지하홀과 달리 빛이 닿는 범위가 크고 움직임은 느리다.
- 성공 시 무대 쪽 빛이 객석 쪽으로 넓어진다. 카드 종류와 무관한 전체 화면 스트로브는 없다.
- 피버는 중앙에서 양쪽 끝까지 부채꼴을 한 번 펼친 뒤 넓게 유지한다. ‘팬과 같이 만드는 후렴’의 인상이다.
- 비 이벤트 중에는 밝기를 소폭 낮추고 역광으로 빗방울을 보이게 한다. 옷차림은 계속 읽힌다.
- 깃발 이벤트에서는 깃발/상단 공간의 빛이 함께 움직인다. 전체 조명도 같은 방향으로 크게 흔들어 읽기를 방해하지 않는다.

스토리의 LUX//FAUNA 헤드라이너 안내를 새로운 랜덤 관객 이탈 이벤트로 재구현하지 않는다.

## 5. Stage 4 — 방송국 생방송

### 다른 스테이지와 가장 크게 달라야 할 점

**밴드가 조명을 흔드는 장소가 아니라, 방송의 큐에 맞춰 밴드가 조명 안으로 들어가는 장소다.** 지하홀의 거친 빨강, 페스티벌의 넓은 보라와 달리 반듯하고 밝고 정밀하다.

‘방송국 = 더 많은 움직이는 스포트라이트’로 만들지 않는다.

### 광원 배치

- 위쪽 스튜디오 면광원 2~3개: 넓고 고정된 중성 백색. 너구리·고슴도치·스컹크를 각각 또렷하게 잡는다.
- 후면 LED: 청회색 바탕과 얇은 흰 선. 공연 중에는 규칙적인 세로/가로 패턴을 유지한다.
- 카메라와 ON AIR 사인: 작은 빨간 탤리등. 이 빨강은 방송 중이라는 표시이지 Mosh 힌트나 실패 표시가 아니다.
- 객석 앞 작은 힌트등: 기존 최다 성향 색. 탤리등과 물리적으로 분리한다.
- 밴드 앞쪽 밝기는 충분히 유지하고 가장자리만 어둡게 하여 프레임 안에 갇힌 긴장을 준다.

### 이야기 연결

- 대기실 대사 ‘빨간 불 들어왔는데’: 카메라 탤리등 켜짐. 이미 방송 중인 것을 대사와 같은 순간에 확인한다.
- 무대 진입: 흰 면광원이 켜지고, 후면의 얇은 LED가 정렬된다. 고슴도치의 카운트인 뒤 바로 조작 가능 상태로 이어진다.
- 매 카드마다 카메라를 새로 이동시키거나 얼굴을 확대하지 않는다. 기존 고정 시점과 조작을 유지한다.

### 기존 룰과 연결

| 상태 | 조명/LED 연출 | 유지할 정보 |
|---|---|---|
| 평상시 | 고정 백색 + 청회색 LED | 복장, 호응, 손패, 시간 |
| 전광판 룰 예고 | 후면 LED의 한 영역만 밝아지고 해당 안내가 켜짐 | 안내가 특정 성향을 지정하면 기존 UI와 같은 색/문구 |
| 룰 진행 | 선택된 LED 영역 유지, 다른 무대광은 안정 | 이벤트 요구와 일반 관객 반응을 구분 |
| 룰 성공 | 같은 LED 영역을 한 번 점등한 뒤 기본 패턴 복귀 | 성공 반응/점수는 기존 UI |
| 정전 진입 | 면광원과 후면 LED가 꺼지고 비상등·방송 오류 연출만 남음 | 기존 정전 룰의 정보 제한과 UI는 유지 |
| 복구 | 백색 면광원 → 후면 LED → ON AIR 강조 순서로 약 0.4초 안에 복구 | 판정은 복구 시점부터 기존 규칙대로 |
| 피버 | 백색 면광원 유지, 후면 LED와 가장자리에 금색 포인트 추가 | 자동 성공처럼 오해시키는 ON AIR 점멸 금지 |

정전 중 Hover 정보 차단·실루엣 등의 기존 제한을 이 조명 기획으로 조용히 해제하지 않는다. 다만 화면 전체를 검은 패널로 가리는 방식은 추가하지 않는다. 시계·카드·이벤트 안내가 읽혀야 한다.

### 실제 플레이 예

세 사람은 완벽히 정렬된 흰 조명 아래 서 있다. 빨간 ON AIR 등은 계속 켜져 있다. 전광판 요구가 뜨면 후면 LED의 일부가 켜져 시선만 유도한다. 정전이 오면 방금까지 완벽했던 화면이 무너지고 비상등과 방송 오류가 남는다. 복구 후 다시 반듯한 빛이 들어오면서 생방송을 수습했다는 감각을 준다.

## 6. Stage 5 — 스타디움 / LUX//FAUNA

### 공간과 이야기

현재 보스는 **아래 우리 무대 / 위 라이벌 무대**다. 좌우 대결로 바꾸지 않는다. 라이벌은 악당이 아니라 빠르고 효과적인 관객 반응을 신뢰하는 프로다. 조명도 ‘추악한 빨강 대 착한 금색’이 아니라 **정밀한 대형 공연과 서로 맞춰 연주하는 밴드의 차이**를 보여준다.

### 두 무대의 언어

| 구역 | 광원 | 움직임 |
|---|---|---|
| 아래 우리 무대 | 중성 백색, 작은 호박색 발광, 관객 성향 힌트 | 처음은 비교적 작은 영역. 성공할수록 무대 가장자리의 점등 구역이 늘어남 |
| 위 LUX//FAUNA | 마젠타·시안, LED 기하학 패턴, 이동 빔·얇은 레이저·스모그 | 클럽/전자음악 페스티벌의 정밀한 스윕·체이스. 드롭에서 크게 펼쳐짐 |
| 사이 관객 이동 공간 | 기본 약한 중성광, 실제 이동 방향을 따라 켜지는 짧은 바닥등 | 이동하는 팬을 따라 점등하고 바로 복귀 |

라이벌 구역이 메인 플레이 화면 위쪽에 걸칠 때는 낮은 밝기만 남긴다. 엿보기/예고로 카메라가 위로 이동할 때 라이벌 공연을 제대로 보여준다. 우리 관객을 라이벌의 긴 빔으로 덮지 않는다.

### LUX//FAUNA — 전자음악 듀오의 공연

- 시안 담당과 마젠타 담당이 서로 응답하는 빛의 흐름. 두 색은 라이벌의 아티스트 테마이며, Chill/Singalong 관객 비율이나 요구 카드의 정답을 뜻하지 않는다.
- 좌우 트러스의 넓은 빔은 천천히 교차하고, 단상 양끝과 상단의 얇은 레이저는 더 빠르게 훑는다. 모든 광원이 같은 각도·속도로 움직이지 않는다.
- 후면 LED는 세로 스캔 → 외곽 체이스 → 기하학 패턴을 구절처럼 번갈아 보여준다. 끊임없는 무작위 점멸로 만들지 않는다.
- 빠른 점멸은 작은 LED 구역에 제한한다. 전 화면 흰색 플래시, 관객 전체의 밝기 진동은 없다. 저점멸 모드에서는 점멸을 부드러운 밝기 변화로 대체한다.
- 스모그는 트러스 하단/단상 양끝에서 짧게 분출하고, 바닥을 따라 퍼져 사라진다. 레이저가 연기를 통과하는 인상을 주되 관객의 얼굴과 Hover 테두리는 가리지 않는다.
- 예고는 빛이 듀오 쪽으로 모이고, 도전 시작은 바깥으로 펼쳐지고, 피버/드롭은 공간을 채운다. 일반 상태와 절정의 차이를 남긴다.
- 음악 박자 검출기는 현재 없다. 첫 구현은 게임 이벤트와 조명 구절 주기를 사용한다. 정확한 비트 동기화는 실제 BGM 재생 위치를 읽는 연결이 검증된 후 추가한다.

배치·렌더링·소유권·구현 순서는 `STAGE_LIGHTING_IMPLEMENTATION_PLAN_KO.md`를 따른다.

### 도입

1. 라이벌의 도입: 위 구역의 시안 LED가 한쪽에서 흐르고 마젠타가 반대쪽에서 응답한다. 두 줄이 만나면 레이저가 펼쳐진다. 실제 곡 시작과 연결하기 전에는 ‘첫 전자음에 동기화’했다고 간주하지 않는다.
2. 너구리의 기타 볼륨 확인: 아래 구역의 작은 스포트가 밴드를 잡는다. 아직 라이벌보다 면적이 작다.
3. 고슴도치의 카운트인: 스컹크를 포함한 세 명의 빛이 연결된다. 새 입력 지연이나 도입부 강제 카드 사용은 없다.

### 팬 쟁탈과 점수 감소

- 팬 영입: 실제로 위→아래 이동하는 관객 경로에 바닥등을 순서대로 켠다. 도착한 뒤 우리 무대 가장자리 조명 한 구역이 추가 점등된다.
- 팬 상실: 같은 경로를 아래→위로 점등한다. 무대를 전부 빨갛게 만들지 않는다.
- 다음 점수 감소 예고: 라이벌 LED 가장자리에 짧은 진행 표시. 이미 존재하는 드레인 카운트다운 UI를 대체하지 않는다.
- 실제 감소: 라이벌 LED 한 구역만 짧게 밝아짐. 반복 드레인이 전체화면 플래시를 일으키면 안 된다.
- 조명 구역 수는 팬 분포의 대략적인 단계만 보여준다. 매 팬마다 Light2D를 새로 만들지 않는다.

### 패턴별 조명 큐

| 기존 패턴 | 예고 | 도전 중 | 성공 |
|---|---|---|---|
| B2B 맞받아치기 | 라이벌 빔 1개가 짧게 전면으로 향함 | 요구 카드색은 미션 안내/작은 전용등에만 표시 | 우리 무대에서 짧게 응답하는 빔 |
| GUEST LIST 팬 영입 | 해당 특별 관객에 후광 | 요청색 후광 유지, 주변 일반 관객도 보임 | 후광이 확장되고 실제 팬 이동 경로 점등 |
| BEATMATCH 흐름 유지 | 후면 LED를 순서대로 켜기 | 카드 성공 횟수에 맞춰 점등 구역 추가. 실제 오디오 박자 시스템을 새로 만들지 않음 | 구역들이 동시에 점등 |
| KILL SWITCH 성향 봉인 | 라이벌 LED의 해당 표시가 꺼짐 | 봉인은 미션 UI가 명시. 객석/성향 힌트등은 꺼서 숨기지 않음 | 기본 LED 배열 복구 |
| DROP / 피버 진입 | 위 구역에서 낮은 빛이 차오름 | 마감 직전 라이벌 배경만 약하게 강도 변화 | 피버 연출이 그대로 이어짐. 별도 피버와 중복 폭발 없음 |

### Revenge Time과 Fever의 공존

- Revenge: 마젠타·시안 테마를 유지하고 LED 체이스와 레이저 교차의 속도·밀도를 높인다. 진홍색 전체 틴트로 바꾸지 않는다. 우리 객석의 힌트색이나 관객 복장은 덮지 않는다.
- Fever: 우리 무대의 백색 역광과 금색 가장자리 점등. 아래는 피버, 위는 라이벌 반격 상태를 동시에 읽을 수 있다.
- Revenge 진입 때문에 기존 카메라 왕복을 새로 만들지 않는다.
- 피버가 끝나면 우리 테마로, Revenge가 끝나면 라이벌의 느린 마젠타·시안 기본 큐로 각각 복귀한다.

### 끝까지 지킬 승패 표현

팬이 0명이 되었다고 라이벌을 격파한 것으로 처리하지 않는다. 현재 보스는 제한시간 종료 시 점수로 판정하며, 라이벌 팬 0명 이후에도 공연이 이어진다.

- 시간 종료 승리: 아래 밴드에 백색 스포트가 모이고 위 라이벌 조명은 낮아진다. 승리 확인 후 짧게 유지하고 결과창으로 넘어간다.
- 패배: 위 무대의 앙코르 조명은 남고 아래는 장비를 정리할 정도의 작업등으로 내려간다. 세 밴드를 완전히 어둠으로 지우지 않는다.
- 라이벌을 악당으로 보이게 하는 폭발·조명 파괴·완전 정전 연출은 지양한다.

## 7. 구현 책임과 연출 충돌 규칙

현재 StageLightController는 좌우 조명을 같은 성향 색으로 제어한다. 이미 추가된 StageGeometry는 위치·각도·반경·스윕을 바꿀 수 있지만, 천장등/바닥등/LED를 독립 제어하거나 고정 테마와 힌트를 나누는 기능은 없다. **현재 Inspector 값만 바꿔 위 기획 전부를 구현할 수 있는 상태는 아니다.**

권장 구현 범위:

1. 기존 성향 힌트 판정은 StageLightEventBridge에 유지한다.
2. 공연장 고정 광원/발광 그림은 각 StageSet에 배치하고 해당 스테이지에서만 켠다.
3. 작은 연출 어댑터 하나가 기존 이벤트를 받아 천장등·LED·바닥등 그룹의 밝기/표시만 바꾼다. 점수·팬 수·타이머·미션 성공을 판정하지 않는다.
4. 보스는 BossPatternAnnounced/Started/Resolved, BossFanMoved, BossDrainApplied, BossRevengeChanged, BossCinematicStarted/Ended 등 기존 이벤트를 재사용한다.
5. 기본 워시는 Light2D, 얇은 LED/사인/바닥등은 기존 Sprite/발광 머티리얼을 우선 사용한다. 작은 장식마다 실시간 광원을 추가하지 않는다.

같은 광원에 여러 스크립트가 동시에 쓰지 않는다. 같은 그룹에서는 정전/종료가 평상시·피버보다 우선한다. 정전 중 특수 성공 플래시가 모든 조명을 재점등하지 않도록 한다. Fever·Revenge는 서로 다른 그룹을 제어한다. Pause 중에는 애니메이션도 멈추고, 새 스테이지에서는 모든 일시적 큐와 밝기를 초기화한다.

## 8. 제작 순서와 완료 기준

### 1차: 공연장별 정지 화면부터

지하 직하광 / 방송 백색 면광원 / 보스 위아래 광원 분리를 먼저 제작한다. 같은 관객·같은 점수라도 정지 화면만 보고 어디인지 구분되어야 한다. Stage 1~3 테마색은 유지한다.

### 2차: 대표 큐 1개씩

- 지하홀: 역광 피버 + 특별 관객 후광.
- 방송국: ON AIR / 기존 정전 진입과 복구.
- 보스: 실제 팬 이동 방향의 바닥등 + Revenge/Fever 분리.
- 골목과 페스티벌의 주변 점등·부채꼴은 다음 순서.

### 검증

- 무대는 빨강이어도 Chill 관객의 복장과 호응을 읽을 수 있는가?
- 조명 테마가 ‘같은 색 카드만 쓰라’는 거짓 힌트를 만들지 않는가?
- 특별 관객 후광이 주변 관객의 Hover를 가리거나 입력을 막지 않는가?
- 방송 탤리의 빨강, Mosh 힌트의 빨강, 사고 경고가 위치/형태로 구분되는가?
- 보스 팬 이동, 드레인, 패턴, Revenge, Fever가 겹쳐도 관객과 손패를 읽을 수 있는가?
- 위쪽 무대 방문 시 광원이 제 위치에 남아 있는가? 카메라에 붙어 따라오지 않는가?
- 팬 0명/미션 성공을 보스전 종료처럼 연출하지 않는가?
- Pause 및 스테이지 전환 후 이전 조명 상태가 남지 않는가?

성공 기준은 ‘화려함’만이 아니라 **장소의 구분, 이야기의 연결, 판정 정보의 가독성**이다.
