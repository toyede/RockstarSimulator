# 기획안 변경 아이디어 정리

핵심 변화는 다음과 같다.

| 기존 | 개편 |
| --- | --- |
| 관객 전체가 열기 상태를 공유 | 관객마다 독립된 몰입도 보유 |
| 관객 다수의 장르만 주로 고려 | 각 관객의 성향과 몰입 단계를 함께 고려 |
| 카드 효과가 관객 전체에 일괄 적용 | 관객별 반응값을 계산한 뒤 합산 |
| 관객 수가 고정적인 구조 | 자연 유입과 이탈로 0~10명 사이에서 변화 |
| 전체 열기 관리 | 개별 관객 유지와 관객 구성 관리 |

## 2. 핵심 플레이 루프

1. 한 곡과 함께 공연을 시작한다.
2. 초기 관객 3명이 등장한다.
3. 초기 관객은 각자 무작위 성향과 `30~50` 사이의 무작위 몰입도를 가진다.
4. 플레이어는 카드 3장을 받는다.
5. 관객별 성향과 현재 몰입 단계를 확인하고 카드 1장을 선택한다.
6. 카드 효과를 관객마다 따로 계산한다.
7. 관객별 반응값을 공연 점수에 합산하고 각 관객의 몰입도에도 반영한다.
8. 카드 1장을 사용하면 새 카드 1장을 드로우해 손패를 다시 3장으로 유지한다.
9. 모든 관객의 몰입도는 공연 내내 자연 감소한다.
10. 몰입도가 0이 된 관객은 공연에서 이탈한다.
11. 공연 중 일정 시간마다 확률적으로 신규 관객이 유입된다.
12. 관객 수는 최대 10명까지 증가할 수 있다.
13. 관객이 0명이 되면 즉시 게임 오버 처리한다.
14. 관객이 남은 상태로 곡이 끝나면 누적 점수와 목표 점수를 비교한다.
15. 목표 점수 이상이면 성공, 미달이면 실패로 처리한다.
16. 공연에서 획득한 점수는 돈으로 환산한다.

## 3. 관객 데이터 구조

관객 한 명은 다음 정보를 가진다.

| 데이터 | 내용 |
| --- | --- |
| 관객 식별자 | 개별 관객을 구분하는 값 |
| 성향 | `Chill`, `Singalong`, `Mosh` 중 하나 |
| 몰입도 | `0~100` 범위의 연속 수치 |
| 몰입 단계 | 몰입도에 따라 결정되는 `차분`, `중간`, `신남` |
| 이탈 경고 표시 | 차분 단계에서만 노출되는 경고 바 |
| 캐릭터 표현 | 현재 몰입 단계에 대응하는 표정과 애니메이션 |

### 3.1 성향

성향은 관객이 어떤 종류의 공연 행동에 잘 반응하는지를 나타낸다.

- `Chill`
- `Singalong`
- `Mosh`

초기 관객과 새로 유입되는 관객의 성향은 무작위로 결정한다. 세 성향의 실제 등장 확률은 밸런스 조정 대상으로 둔다.

### 3.2 몰입도와 표시 단계

몰입도는 내부적으로 `0~100`의 연속 수치로 관리하지만, 플레이어에게는 세 단계로 단순화해 보여준다.

| 몰입도 | 표시 단계 | 이탈 경고 바 | 결과 |
| --- | --- | --- | --- |
| 0 | 퇴장 | 바가 모두 소진됨 | 해당 관객 이탈 |
| 1~33 | 차분 | 표시 | 이탈 위험 |
| 34~66 | 중간 | 숨김 | 공연 관람 유지 |
| 67~100 | 신남 | 숨김 | 높은 반응 상태 |

차분 상태의 경고 바는 별도의 이탈 타이머가 아니라 현재 몰입도 자체를 시각화한다.

`경고 바 비율 = 현재 몰입도 ÷ 33`

몰입도 33에서는 경고 바가 가득 차 있고, 몰입도가 0에 가까워질수록 바가 줄어든다. 중간 이상으로 회복되면 경고 바를 숨긴다. 이후 다시 차분 단계에 진입하면 그 시점의 몰입도에 맞는 경고 바를 표시한다.

### 3.3 몰입도 자연 감소

모든 관객의 몰입도는 공연 내내 지속해서 감소한다. 카드 사용으로 얻는 양의 반응값만 몰입도를 회복시킬 수 있다.

개념식은 다음과 같다.

`시간 경과 후 몰입도 = 기존 몰입도 - 초당 자연 감소량 × 경과 시간`

초당 자연 감소량은 아직 고정하지 않으며 핵심 밸런스 조정 항목으로 둔다. 카드 효과가 없는 상태에서 몰입도 33인 관객이 이탈하기까지 걸리는 시간은 다음 관계로 계산할 수 있다.

`차분 상태 최대 잔류 시간 = 33 ÷ 초당 자연 감소량`

## 4. 관객 유입과 이탈

### 4.1 초기 관객

- 시작 인원: 3명
- 성향: 관객마다 무작위
- 초기 몰입도: 관객마다 `30~50` 사이 무작위

초기 관객 중 일부는 차분 상태로 시작할 수 있으므로 공연 초반부터 관객 관리가 필요하다.

### 4.2 일반 신규 유입

- 공연 중 일정 시간마다 신규 관객 유입 여부를 확률적으로 판정한다.
- 유입된 관객의 성향은 무작위다.
- 유입된 관객의 초기 몰입도는 `30~50` 사이 무작위다.
- 현재 관객이 10명이면 추가 유입은 발생하지 않는다.

유입 판정 주기와 확률은 아직 고정하지 않는다. 두 값을 함께 조정해 한 공연에서 기대되는 평균 관객 수와 최대 관객 도달 빈도를 결정한다.

### 4.3 이탈과 게임 오버

- 몰입도가 0이 된 관객은 즉시 퇴장한다.
- 퇴장한 관객은 점수 계산 대상에서 제거된다.
- 관객이 한 명도 남지 않으면 곡이 끝나기 전이라도 즉시 게임 오버 처리한다.

## 5. 카드 시스템

### 5.1 손패와 드로우

- 공연 시작 시 카드 3장을 지급한다.
- 플레이어가 카드 1장을 사용하면 새 카드 1장을 드로우한다.
- 기본 손패 수는 3장으로 유지한다.

카드 사용 가능 간격, 전체 덱의 크기, 카드 중복 수, 셔플과 소진 규칙은 카드 풀을 확정할 때 함께 설계한다.

### 5.2 카드별 점수 데이터

각 공연 카드는 성향별 점수 3개와 현재 몰입 단계별 점수 3개를 가진다.

| 성향 점수 | Chill | Singalong | Mosh |
| --- | --- | --- | --- |
| 카드별 설정값 | 조정 대상 | 조정 대상 | 조정 대상 |

| 몰입 단계 점수 | 차분 | 중간 | 신남 |
| --- | --- | --- | --- |
| 카드별 설정값 | 조정 대상 | 조정 대상 | 조정 대상 |

각 카드의 여섯 수치는 카드의 역할과 사용 대상을 결정하는 핵심 밸런스 데이터다.

### 5.3 관객별 반응값

카드를 사용하기 직전의 관객 성향과 몰입 단계를 기준으로 계산한다.

`관객 반응값 = 성향 점수 + 현재 몰입 단계 점수`

최종 반응값은 0 미만이 되지 않는다.

`최종 관객 반응값 = max(0, 성향 점수 + 현재 몰입 단계 점수)`

- 반응값이 0이면 공연 점수와 해당 관객의 몰입도가 증가하지 않는다.
- 반응값이 양수이면 공연 점수와 해당 관객의 몰입도가 함께 증가한다.
- 카드 사용으로 공연 점수나 관객 몰입도가 직접 감소하는 경우는 없다.
- 부적합한 카드의 손해는 자연 감소를 상쇄하지 못하는 방식으로 발생한다.

### 5.4 카드 한 장의 전체 점수

현재 관객 전원의 반응값을 각각 계산한 뒤 합산한다.

`카드 전체 점수 = Σ 현재 관객별 최종 반응값`

카드 전체 점수는 공연 누적 점수에 더한다. 공연 누적 점수는 감소하지 않고 유지되거나 증가한다.

`공연 누적 점수 = 기존 누적 점수 + 카드 전체 점수`

### 5.5 개인 몰입도 반영

같은 관객 반응값을 해당 관객의 개인 몰입도에도 반영한다.

`변경 후 몰입도 = clamp(기존 몰입도 + 최종 반응값 × 몰입도 적용 배율, 0, 100)`

몰입도 적용 배율은 아직 고정하지 않는다. 점수값을 그대로 적용할지, 전체 공통 배율 또는 카드별 배율을 사용할지는 밸런스 테스트 결과로 결정한다.

## 6. 카드 계산 예시

다음 수치는 현재 확정된 전체 카드 기준이 아니라, 제안된 `박수 리듬 유도` 카드의 계산 예시다.

### 6.1 박수 리듬 유도

| 성향 | Chill | Singalong | Mosh |
| --- | --- | --- | --- |
| 성향 점수 | +1 | +2 | +3 |

| 현재 몰입 단계 | 차분 | 중간 | 신남 |
| --- | --- | --- | --- |
| 단계 점수 | +1 | +2 | +3 |

### 6.2 관객 2명 계산

| 관객 | 성향 | 현재 상태 | 성향 점수 | 상태 점수 | 최종 반응값 |
| --- | --- | --- | --- | --- | --- |
| A | Mosh | 중간 | +3 | +2 | +5 |
| B | Chill | 신남 | +1 | +3 | +4 |
| 합계 |  |  |  |  | **+9** |

카드 전체 점수는 9점이며 공연 누적 점수에 9점을 더한다. 몰입도 적용 배율이 1인 경우에만 A의 몰입도는 5, B의 몰입도는 4 증가한다. 적용 배율은 별도 조정 항목이므로 이 예시에서 확정하지 않는다.

### 6.3 예시 카드의 관객 수별 점수 범위

박수 리듬 유도 카드의 관객 1인당 반응값은 최소 2, 최대 6이다.

| 현재 관객 수 | 카드 최소 총점 | 카드 최대 총점 |
| --- | --- | --- |
| 3명 | +6 | +18 |
| 7명 | +14 | +42 |
| 10명 | +20 | +60 |

이 표는 박수 리듬 유도 카드에만 해당한다. 실제 카드별 점수 범위는 각 카드의 성향·몰입 단계 점수표에 따라 달라진다.

## 7. 스몰토크 카드

### 7.1 목적

스몰토크는 저몰입 관객을 새 관객으로 교체하고, 현재 관객의 성향 구성을 다시 맞출 기회를 제공하는 제어형 리롤 카드다.

### 7.2 발동 규칙

1. 스몰토크 카드를 사용하면 관객 교체 상태가 시작된다.
2. 교체 상태는 최대 10초 동안 지속된다.
3. 현재 관객을 몰입도가 낮은 순서로 정렬한다.
4. 1초마다 몰입도가 가장 낮은 관객 1명이 퇴장한다.
5. 같은 시점에 새 관객 1명이 입장한다.
6. 한 명이 나가고 한 명이 들어오므로 전체 관객 수는 유지된다.
7. 새 관객의 성향은 무작위다.
8. 새 관객의 초기 몰입도는 `30~50` 사이 무작위다.
9. 플레이어가 원하는 성향 구성이 되었다고 판단해 다른 카드를 내면 교체를 즉시 중단한다.

### 7.3 전략적 의미

- 이탈 위험이 높은 관객부터 제거할 수 있다.
- 무작위 유입 결과를 보며 원하는 시점에 리롤을 멈출 수 있다.
- 관객 수를 잃지 않고 성향 구성을 바꿀 수 있다.
- 새 관객도 `30~50` 몰입도로 입장하므로 교체 직후 적합한 카드 연결이 필요하다.

### 7.4 구현 전 확정할 세부 규칙

다음 항목은 현재 기획 범위에서 임의로 정하지 않는다.

- 스몰토크 중에도 곡의 남은 시간이 계속 흐르는지 여부
- 스몰토크 중에도 관객 몰입도의 자연 감소가 계속되는지 여부
- 새로 들어온 관객이 같은 스몰토크에서 다시 최저 몰입 관객이 되어 재교체될 수 있는지 여부
- 현재 관객이 10명 미만이어도 최대 10회의 교체를 허용하는지 여부
- 스몰토크 카드 자체의 점수 또는 몰입도 효과 유무

## 8. 공연 종료와 보상

### 8.1 종료 판정

| 시점 | 조건 | 결과 |
| --- | --- | --- |
| 공연 도중 | 관객 수가 0명 | 즉시 게임 오버 |
| 곡 종료 | 누적 점수 ≥ 목표 점수 | 공연 성공 |
| 곡 종료 | 누적 점수 < 목표 점수 | 공연 실패 |

### 8.2 점수의 돈 환산

공연에서 얻은 점수는 공연 종료 후 돈으로 환산한다. 이번 기획 범위는 돈으로의 환산까지이며, 돈을 사용하는 동료 영입과 장비 업그레이드의 가격·효과 설계는 포함하지 않는다.

다음 보상 수치는 밸런스 조정 대상으로 둔다.

- 점수와 돈의 환산 비율
- 성공 시 추가 보너스 유무와 크기
- 목표 점수 미달 또는 게임 오버 시 환산 여부
- 화면에 표시하는 점수·돈의 시각적 확대 단위

## 9. 연출과 사운드 방향

| 상황 | 방향 |
| --- | --- |
| 관객 입장 | 뒤에서 길을 걷던 관객이 공연에 이끌려 합류(뒤에서 작게 이동하다가 커지면서 앞으로 이동) |
| 관객 이탈 | 차분 상태에서 경고 바가 줄고, 0에서 공연장을 떠남(현재 위치에서 뒤로 가고 화면 밖으로 나감) |
| 중간·신남 상태 | 경고 바를 숨기고 표정과 동작으로 몰입도를 표현 |
| 스몰토크 | 짧은 말소리형 키음과 대화 연출 |
| 관객 교체 | 낮은 몰입도 관객 퇴장과 새 관객 입장을 1초 단위로 명확히 표시 |
| 공연 카드 | 약 1~2초의 짧은 효과음 또는 보이스 |
| 박수 유도(공연 카드의 일종) | “박수 짝짝!”처럼 행동을 바로 이해할 수 있는 짧은 멘트 |

기존 아이디어에 있던 `장르 선택 카드에서 20~30초 BGM 재생`은 현재 확정된 `한 곡 2분 30초~3분 공연` 구조와 재생 시간 기준이 다르다. 장르 선택 카드를 유지할지와 BGM 재생 단위는 후속 카드 확장 기획에서 별도로 정한다.

### 10.1 자연 감소와 카드 회복의 관계

카드 한 번의 평균 회복량은 다음 카드 사용 전까지 발생하는 자연 감소량과 비교해야 한다.

`카드 사이 자연 감소량 = 초당 자연 감소량 × 평균 카드 사용 간격`

`관객 순회복량 = 관객 반응값 × 몰입도 적용 배율 - 카드 사이 자연 감소량`

- 순회복량이 항상 크게 양수면 관객 이탈이 거의 발생하지 않는다.
- 순회복량이 대부분 음수면 올바른 카드를 사용해도 관객을 유지하기 어렵다.
- 0점 반응을 받은 관객은 자연 감소량을 그대로 감수한다.

### 10.2 관객 수에 따른 점수 확대

카드 전체 점수는 관객별 반응값의 합이므로 관객 수가 3명에서 10명으로 늘면 같은 카드의 영향력도 크게 증가한다.

이 구조는 `관객 관리 성공 → 더 많은 관객 → 더 높은 점수`의 보상 흐름을 만든다. 동시에 초반에 관객을 빠르게 늘린 플레이가 목표 점수 달성에서도 유리해지는 눈덩이 효과가 발생한다. 목표 점수는 고정된 카드 1장 값이 아니라 공연 전체의 예상 카드 사용 횟수와 평균 관객 수를 기준으로 산정해야 한다.

개념식은 다음과 같다.

`예상 공연 점수 = Σ(각 카드 사용 시점의 관객 수 × 관객 1인당 평균 반응값)`

### 10.3 고몰입 눈덩이

신남 단계 점수를 높게 설정하면 이미 몰입도가 높은 관객이 더 많은 점수와 회복량을 제공한다. 이 구조는 좋은 플레이에 보상을 주지만, 신남 상태가 지나치게 오래 고정될 수 있다.

카드별 상태 점수, 자연 감소량, 몰입도 적용 배율을 함께 조정해 다음 두 카드 역할이 공존하도록 한다.

- 차분 관객을 살리는 회복용 카드
- 중간·신남 관객에게 높은 점수를 얻는 득점용 카드

## 14. 기획 완료 기준

- 관객마다 성향과 몰입도를 독립적으로 계산한다.
- 몰입도는 내부 수치 `0~100`, 화면 표시 `차분/중간/신남`으로 구분한다.
- 모든 관객의 몰입도가 공연 중 지속해서 감소한다.
- 몰입도 1~33에서 이탈 경고 바가 보이고 0에서 퇴장한다.
- 초기 관객은 3명이며 신규 유입을 포함한 최대 관객은 10명이다.
- 카드 반응값은 성향 점수와 현재 몰입 단계 점수의 합으로 계산한다.
- 최종 반응값은 0 미만이 되지 않으며 공연 점수와 개인 몰입도에 함께 반영한다.
- 카드 1장을 사용하면 카드 1장을 드로우해 3장 손패를 유지한다.
- 스몰토크는 낮은 몰입도 관객부터 1초에 1명씩 교체하고 다른 카드로 중단할 수 있다.
- 관객 0명은 즉시 게임 오버, 곡 종료 시 목표 점수 달성 여부로 성공·실패를 판정한다.
- 공연 점수는 돈으로 환산한다.
- 확정되지 않은 수치는 밸런스 조정 대상으로 분리하고 임의의 최종값을 사용하지 않는다.
